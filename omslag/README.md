# Omslag

Denna mapp innehåller skapad omslagsbild/framsida för romanen.

## Fil
- `omslag_mannen_i_korridoren.png`

## Omslagsinformation
- Titel: Mannen i korridoren
- Undertitel: Ingenstans är nog långt borta
- Författare: Erland Lindmark
- Status: Skapad

## Högupplösta omslag för publicering

Följande separata omslagsfiler finns för publicering, exempelvis Apple Books:

- `mannen_i_korridoren_cover_1800x2700.png` – högupplöst PNG, 1800 × 2700 px.
- `mannen_i_korridoren_cover_1800x2700.jpg` – högupplöst JPG, 1800 × 2700 px.

JPG-versionen rekommenderas normalt för uppladdning på grund av mindre filstorlek. PNG-versionen sparas som högkvalitativ reserv.
